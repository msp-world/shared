# shared

`msp-world-cli` 各节点共用的 MSP 适配层，负责导出协议类型、节点配置、清单校验和关闭钩子。

本仓库作为 [msp-world-cli](https://github.com/msp-world/msp-world-cli) 的 `src/shared` 子模块使用，依赖主仓库中的 `msp-ts` 子模块。请通过主仓库递归克隆。

## 来源与致谢

协议实现来自 [msp-ts](https://github.com/msp-world/msp-ts)；其 MIT 许可证中的版权署名为 hxh230802。World 生态的上游与作者见各节点仓库。
